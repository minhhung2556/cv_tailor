Job description

Remote
Flutter DartFlutter rendering pipeline

This role is for someone who obsesses over detail, performance, and fluid interaction. You care about every pixel, every interaction, and every transition—and the performance behind them. You have a deep understanding of Flutter architecture and take pride in writing clean, maintainable, and well-architected code. 


Responsibilities

  • Own production code end to end, proactively preventing regressions and fragile implementations
  • Architect, build, and maintain high-performance Flutter applications in production
  • Write clean, efficient, and well-documented code that follows Flutter best practices
  • Deliver reliable UI implementations with meticulous visual accuracy
  • Build fluid interfaces, smooth transitions, and responsive layouts
  • Refactor and improve the existing codebase to reduce technical debt and maintain code quality
  • Design scalable UI architecture and reusable component systems
  • Optimize rendering performance to deliver smooth, consistent interactions at appropriate device refresh rates
  • Keep applications fast, stable, and memory-efficient across supported devices
  • Contribute to architecture discussions and code reviews to uphold high engineering standards


Required Skills & Qualifications

  • 3+ years of professional experience developing Flutter applications
  • Fluent in Flutter and Dart
  • Proven experience building and supporting large-scale Flutter applications in production
  • Strong understanding of the Flutter rendering pipeline (Widget → Element → RenderObject)
  • Strong understanding of Flutter rendering, layout, and widget lifecycles
  • Strong knowledge of state-management approaches such as BLoC, Riverpod, and Provider
  • Strong experience optimizing app performance and memory usage
  • Proven ability to write clean, maintainable, and well-documented production code


Good to have

  • Experience designing scalable frontend architectures


Engineering Standards

  • Treat code quality, efficiency, and maintainability as core priorities
  • Take a proactive approach to preventing and resolving production regressions
  • Ensure frontend systems remain scalable as the product grows


Non-Functional Requirements

  • Excellent written and verbal English communication skills
  • Ability to collaborate closely with designers, backend engineers, product managers, and QA engineers
  • Strong ownership and accountability throughout the development lifecycle
  • Self-driven and able to solve complex problems independently
  • A strong commitment to craftsmanship in product development
